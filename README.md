# Claude 한국어 고유어 편향 실험

Claude가 쓴 한국어 글에는 '이유' 대신 '까닭', '속도' 대신 '빠르기'처럼 고유어가 자주 나온다는 관찰이 있습니다.
이 저장소는 그 원인이 **텍스트 워터마킹**인지 확인하는 도구입니다.

## 무엇을 확인하는가

Anthropic 문서에 따르면 Claude 4.x 모델은 요청에 기본값이 아닌 샘플링 파라미터(`temperature`, `top_p`, `top_k`)가 있으면 워터마크가 실리지 않을 수 있습니다.
그래서 같은 프롬프트를 두 가지 설정으로 여러 번 생성해서 단어 선택을 비교합니다.

| 설정 | 요청 | 워터마크 |
|---|---|---|
| A | 샘플링 파라미터 없음 | 실림 |
| B | `temperature: 0.99` | 실리지 않을 수 있음 |

`temperature` 1.0과 0.99는 단어 확률을 거의 바꾸지 않습니다. 두 설정의 글에서 고유어 비율이 다르면 원인은 워터마킹 쪽에 있습니다.

| 가설 | 예측 |
|---|---|
| 워터마킹이 원인이다 | 설정 A의 고유어 비율이 설정 B보다 높다 |
| 학습된 문체가 원인이다 | 두 설정의 고유어 비율이 같다 |

## 설치

Python 3.10 이상이 필요합니다.

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python tests/test_all.py        # API 키 없이 도구가 제대로 동작하는지 확인
```

`anthropic` SDK는 1.x로 고정합니다. 2.x는 API 버전 `2026-10-21`을 보내고, 이 버전은 `temperature`를 모든 모델에서 거부합니다.

## 실행

API 키는 `ANTHROPIC_API_KEY` 환경 변수로 넣습니다.

```bash
export ANTHROPIC_API_KEY=...

# 1. 두 설정의 샘플링이 실제로 다른지 확인 (600회 호출, 응답이 한두 단어라서 비용이 작습니다)
python generate.py probe
python analyze.py probe data/probe.jsonl

# 2. 본 실험 (프롬프트 12개 x 설정 2개 x 10편 = 240회 호출)
python generate.py main --dry-run     # 호출 계획만 확인
python generate.py main
python analyze.py --show-hits 2 --json data/main_result.json ab data/main.jsonl
```

- 기본 모델은 `claude-opus-4-6`입니다. 원고를 쓸 때 사용한 모델이 다르면 `--model claude-sonnet-4-6`처럼 바꿉니다. 가능한 모델은 `claude-opus-4-6`, `claude-sonnet-4-6`, `claude-opus-4-5`, `claude-haiku-4-5`입니다. 4.7 이후 모델은 샘플링 파라미터를 거부하므로 이 실험을 할 수 없습니다.
- 실행이 중간에 멈추면 같은 명령을 다시 실행합니다. 빠진 응답만 채웁니다.
- 원고를 쓸 때 사용한 지시문이 있으면 `--system-file 지시문.txt`로 넣을 수 있습니다.
- 프롬프트는 `prompts.json`에서 고칩니다. 비교할 단어(이유, 속도, 방법 등)가 프롬프트에 들어가지 않게 썼습니다. 프롬프트에 있는 단어는 모델이 그대로 따라 쓰기 때문입니다.

### 예상 비용

글 한 편의 출력을 약 1,000토큰으로 가정한 값입니다. 실제 토큰 수는 `generate.py`가 끝날 때 출력합니다. 가격은 2026년 11월 3일 기준입니다.

| 모델 | 본 실험 240회 | probe 600회 |
|---|---|---|
| `claude-opus-4-6` | 약 6달러 | 1달러 미만 |
| `claude-sonnet-4-6` | 약 4달러 | 1달러 미만 |
| `claude-haiku-4-5` | 약 1달러 | 1달러 미만 |

## 결과 읽는 법

`analyze.py ab`는 여섯 가지를 계산합니다.

1. **고유어 표지**: `lexicon.json`에 적힌 고유어가 어절 1,000개당 몇 번 나오는가
2. **쌍별 고유어 선택**: '까닭'과 '이유'처럼 뜻이 같은 쌍에서 고유어를 고른 비율
3. **드문 한자어**: '연유', '방도' 같은 드문 한자어의 빈도. 워터마킹이 드문 단어 전반을 늘리는지 보는 대조군입니다.
4. **지시어**: '이', '그', '그것' 같은 지시어의 빈도
5. **어휘 전체 비교**: 단어 목록에 의존하지 않고, 모든 내용어의 빈도 분포가 두 설정에서 다른지 검정합니다.
6. **어휘 다양도**: 같은 분량 안에 서로 다른 단어가 얼마나 나오는가

각 비율에는 설정 A와 B의 비(A/B), 95% 신뢰구간, 유의확률 p가 붙고, 아래 기준으로 판정합니다.

| 판정 | 기준 |
|---|---|
| 사실상 같다 | A/B의 95% 신뢰구간이 0.8~1.25 안에 들어옴 |
| A가 높다 (낮다) | 신뢰구간이 1보다 위(아래)에 있고 p < 0.05 |
| 판단 보류 | 위 두 경우가 아님. `--n` 값을 올려서 표본을 늘려야 합니다 |
| 판단할 수 없음 | 해당 단어가 두 설정을 합쳐 20회 미만 |

probe 결과와 본 실험 결과를 함께 읽습니다.

| probe 결과 | 본 실험의 고유어 비율 | 해석 |
|---|---|---|
| 샘플링이 다르다 | 사실상 같다 | 워터마킹은 고유어 편향의 원인이 아닙니다. 가장 강한 반증입니다. |
| 샘플링이 다르다 | A가 높다 | 워터마킹 가설을 지지합니다. 3번에서 드문 한자어도 함께 늘었는지 확인합니다. |
| 차이를 찾지 못함 | 사실상 같다 | 약한 증거입니다. 설정 B에서 워터마크가 꺼졌는지 알 수 없습니다. |
| 무엇이든 | 판단 보류 | 표본을 늘립니다. |

probe는 같은 프롬프트에 대한 짧은 답(숫자 하나, 과일 이름 하나)의 분포를 두 설정에서 비교합니다. 워터마크는 비밀 키와 앞 단어 몇 개로 단어 선택을 정합니다. 그래서 문맥이 같으면 선택이 같은 단어로 치우치고, 워터마크가 한 설정에서만 켜져 있으면 답의 분포가 달라집니다. 이 예측은 Anthropic이 공개한 작동 방식에서 추론한 것이고, Anthropic이 보증한 확인 방법은 아닙니다.

## API 없이 하는 비교

폴더 두 개에 `.txt`나 `.md` 파일을 넣으면 같은 분석을 할 수 있습니다.

```bash
python analyze.py dirs --a 이전_원고 --b 이후_원고
```

- **날짜 비교**: 워터마킹 적용일 이전에 생성한 원고와 이후에 생성한 원고를 비교합니다. 적용일 이전 원고에도 고유어가 같은 비율로 나오면 워터마킹은 원인이 아닙니다.
- **사람 글 대조**: Claude가 쓴 글과 같은 분야에서 사람이 쓴 글을 비교하면 고유어 편향의 크기를 잴 수 있습니다.

긴 파일은 어절 300개 안팎의 조각으로 나눠서 비교합니다(`--chunk`). 한 파일에서 나온 조각들은 서로 독립이 아니므로, 파일 수가 적으면 신뢰구간이 실제보다 좁게 나옵니다.

Anthropic 출시 노트에서 확인한 워터마킹 적용일은 다음과 같습니다. 표에 없는 모델의 적용일은 확인하지 못했습니다.

| 적용일 | 모델 |
|---|---|
| 2026-09-01 | Fable 5.1, Mythos 5.1 |
| 2026-11-03 | Mythos 5, Opus 4.7, Sonnet 4.6 |
| 2026-11-16 | Opus 4.6, Opus 4.5, Sonnet 4.5, Haiku 4.5 |

`samples/` 폴더에는 도구 검증에 쓴 Claude 글 24편이 있습니다. 같은 조건에서 쓴 글을 두 묶음으로 나눈 것이므로 차이가 없어야 정상입니다.

```bash
python analyze.py dirs --a samples/A --b samples/B --chunk 0
```

## 집계 항목 고치기

비교할 단어는 `lexicon.json`에 있습니다. 직접 읽으면서 거슬렸던 단어를 추가하면 됩니다.

- 항목은 `형태/품사` 형식의 형태소입니다. 형태소 분석에는 [Kiwi](https://github.com/bab2min/Kiwi)를 씁니다.
- 동음이의어는 품사로 구분합니다. `세/VV`는 '세다(count)'만 세고, '세 가지'의 `세/MM`이나 '힘이 세다'의 `세/VA`는 세지 않습니다.
- 글이 어떻게 분석되는지는 `python analyze.py tokens 파일.txt`로 확인합니다.
- `--show-hits 3`을 붙이면 고유어 표지가 나온 문맥을 항목마다 3개씩 출력합니다. 엉뚱한 단어가 집계되는지 여기서 확인합니다.

## 한계

- Anthropic 문서의 표현은 워터마크가 "실리지 않을 수 있다"입니다. 설정 B에서 워터마크가 꺼졌는지는 probe로 간접 확인만 할 수 있습니다. 확정하려면 Anthropic의 워터마크 감지 API가 필요한데, 이 API는 비공개 미리보기 단계입니다.
- 4.x 모델에서만 할 수 있는 실험입니다. 5.x 모델의 워터마킹 영향은 이 실험으로 알 수 없습니다.
- API 요청에는 claude.ai 앱의 시스템 프롬프트가 없습니다. 앱에서 쓴 글과 조건이 다릅니다.
- 고유어 표지 목록은 사람이 고른 목록입니다. 5번 어휘 전체 비교가 이 약점을 보완합니다.
- 이 실험은 API 버전 `2023-06-01`과 4.x 모델에 의존합니다. 둘 중 하나가 종료되면 실험할 수 없습니다.
